# 本地小说阅读器

**v1.0 build 20261028**

一个**单文件**的本地电子书阅读器。不用联网、不用安装、不用构建——双击 HTML，用浏览器打开就能读。

书的内容、阅读进度、设置全部只留在你自己的浏览器里，不联网、不上传。

---

## ✨ 功能

### 📖 多格式，开箱即读

| 格式 | 支持情况 |
|:--|:--|
| **TXT** | 自动识别「第 X 章 / 卷 / 回」「楔子」「序章」「番外」「大结局」等章节标题 |
| **EPUB** | 按 spine 顺序解析，插图按原位置渲染；自动检测 DRM |
| **Markdown** | `#` ~ `######` 分章，去掉标记保留正文 |
| **HTML** | `h1` ~ `h3` 分章，`h4` ~ `h6` 保留为正文 |
| **ZIP** | 自动挑包内最大的 txt 来读 |

### 🔤 中文编码全兼容

- 自动识别 **UTF-8 / GBK / GB18030 / Big5 / UTF-16**
- 繁体 Big5 老书、GBK 简体书都不会乱码
- 内置批量转码：把文件从原编码转成 UTF-8 导出，不改原文件

### 🎨 读得舒服

- 4 套皮肤：浅色 / 深色 / 护眼 / 跟随系统
- 字号、行高、段距、正文宽度、字体全部可调
- 改完字号不会跳回章首——记住的是具体段落
- 双击正文开启自动滚屏，速度随拖随生效
- 目录跳章、左右方向键翻章

### 🧹 正文净化

一键清理网络小说里常见的脏东西：

多余空行 · 控制字符与零宽字符 · 全半角混乱 · 不规范标点 · 行内网址与联系方式 · 广告和站点话术（简繁都认）· 对话换行错乱 · 首行缩进不统一

### 🔄 简繁一键切换

自动判断当前书是简体还是繁体，点一下互转。切换是**原地替换文字**，不重绘页面、不跳位置，上千章也是秒切。

### 📌 进度永不丢

- 按**文件内容**认书：同名不同书不会串，改了文件名照样续读
- 精确到段落：换字号、改窗口大小都回到原来那一段
- 关窗口前立即保存，不丢最后一屏

### 💾 数据可迁移

设置和全部阅读进度可导出成 JSON，换电脑导入即恢复。

---

## 📥 使用

1. 下载 [`本地小说阅读器.html`](本地小说阅读器.html)
2. 双击打开（或拖进浏览器窗口）
3. 把小说文件**拖进页面任意位置**，或点右上角「打开本地小说」
4. 开读

> 不需要服务器、不需要 Node、不需要任何依赖。整个程序就是一个 HTML 文件。

## ⌨️ 快捷键

| 按键 | 功能 |
|:--|:--|
| `O` | 打开 / 关闭设置 |
| `C` | 打开 / 关闭目录 |
| `←` / `→` | 上一章 / 下一章 |
| `Esc` | 关闭弹窗 |
| 双击正文 | 开始 / 停止自动滚屏 |

## 🔒 隐私

- 零网络请求，零账号，零统计
- 书的内容不写入磁盘，只留在内存里
- 进度与设置存在浏览器 `localStorage`，清空浏览器数据即彻底删除

## 🛠 给开发者

单文件实现：JSZip、jschardet、zh-convert、purify 等第三方库全部内联，保持「拷走就能用」。没有构建步骤，改完刷新即生效。

源码分四段：内联第三方库 → 样式 → DOM 骨架 → 应用脚本（一个 IIFE，按「常量/存储 → 解析器 → 编码 → 渲染 → 打开书 → 导入导出 → 事件」分区，每段都有注释标题，按注释找即可）。
