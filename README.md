# 本地小说阅读器

一个**单文件**的本地电子书阅读器，无需联网、无需安装，用浏览器打开即可使用。支持 TXT、EPUB、Markdown、HTML 等格式。

## ✨ 功能特性

- 📖 **多格式支持**：TXT / EPUB / Markdown / HTML / 压缩包(内含 txt)
- 🎨 **阅读设置**：字号、行距、正文宽度、外观主题
- 🧹 **内容优化**：压缩空行、清除控制/零宽字符、全角半角统一、规范标点、剔除行内网址/联系方式、删广告/站点话术、修复对话换行、首行缩进
- 📌 **记忆位置**：自动记住上次阅读位置
- 🔤 **字符编码转换**：批量把文本从各种编码（GBK / GB18030 / Big5 / UTF-16 等）转成 UTF-8
- 🔒 **纯本地**：无网络请求，数据只存在本地，隐私安全

## 📥 使用

1. 下载 `本地小说阅读器.html`
2. 用浏览器（Chrome / Edge / Safari 等）打开
3. 把小说文件拖进窗口，或点右上角「打开」选择文件
4. 开始阅读

## 🔒 隐私

纯本地运行，所有数据只保存在你自己的浏览器里，不联网、不上传。
